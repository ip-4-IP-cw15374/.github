<h2>一、地址数量的来源</h2>
<p>一条专线能分几个IP，首先看运营商卖给你的是单个地址还是一段地址。单个地址只能做端口映射，一段地址才能分给多台设备各自持有。</p>
<p>其次是接入设备的接口能力。设备外网口能挂几个地址，决定了这一段地址能不能同时上线，很多光猫默认只允许一个。</p>
<p>第三是运营商侧的约束，比如是否允许地址同时在线、是否限制地址与终端绑定。开通前把这三条问清楚，比事后返工省时间。</p>
<h2>二、四个地址的常见形态</h2>
<p>四个IP通常是连续的一段，比如同网段内四个可用地址，其中首尾可能被网关和广播占用，实际可用数量要以开通单为准。</p>
<p>四个地址不等于四倍带宽。总带宽由专线速率决定，四个地址只是四个出口身份，同时跑满时还是要平分这条线路。</p>
<h3>一段四地址的掩码怎么看</h3>
<p>常见的四地址段对应三十位掩码，可用主机地址两个；八地址段对应二十九位，可用六个。拿到地址先算掩码，别凭感觉填。</p>
<p>掩码算错会导致地址冲突或者网关不可达，症状是所有地址都不通。遇到这种情况先复核掩码和网关，再怀疑线路。</p>
<h2>三、四个IP的分工写法</h2>
<p>最简单的分工是每个地址对应一类用途，比如一个做日常浏览，一个做后台管理，一个做数据采集，一个留作备用。用途固定以后排查很快。</p>

<h2>四、路由器上的地址配置</h2>
<p>进入路由器的外网设置，选择静态地址模式，逐条填入地址、掩码和网关。多条地址用同一个网关，不要给每条地址配不同网关。</p>
<h3>怎么核对四条地址都在</h3>
<p>填完之后在设备上执行地址查询，确认四条记录都在。有的固件只显示主地址，需要在高级页面或者命令行里看完整列表。</p>
<h3>给下游主机分配出口</h3>
<p>下游主机要指定走哪个地址，有两种做法：按源地址策略路由，或者按端口分组。前者对主机透明，后者对业务友好。</p>
<h2>五、验证与常见误区</h2>
<p>验证分三步：设备能否同时持有四个地址、每个地址能否独立访问外网、业务侧看到的出口是否与预期一致。三步都过才算配置完成。</p>
<p>常见误区是把地址当成带宽买，或者把四个地址都指到同一台主机上。前者浪费预算，后者等于只用一个地址，其余三个闲置。</p>
<p>还有一个误区是忽略地址与设备的绑定。有些线路要求地址只能由指定设备使用，换了设备要重新报备，否则地址会被拒。</p>

<h2>六、扩容与长期使用</h2>
<p>四个地址用满以后，扩容有两种方式：在同一段内追加地址，或者再开一条专线做分流。前者配置简单，后者隔离性更好。</p>
<p>长期使用要给地址做台账，记录开通时间、用途和更换记录。地址被目标侧限制时，台账能帮你快速判断是普遍问题还是单点问题。</p>
<h2>常见问答</h2>
<h3>四个IP是同时在线还是轮流使用？</h3>
<p>答：取决于运营商规则和你的配置，多数静态段支持同时在线，逐个地址独立持有。</p>
<h3>四个地址可以给四台不同的服务器用吗？</h3>
<p>答：可以，把每个地址静态指向对应服务器即可，服务器侧只需配置地址和网关。</p>
<h3>一条专线的带宽会因为分四个IP而变小吗？</h3>
<p>答：不会变小，总带宽由线路速率决定，多个地址共享同一条链路。</p>
<h3>四个地址都能做端口映射吗？</h3>
<p>答：都能，但映射端口不能冲突，同一个端口在不同地址上可以各自映射到不同内网主机。</p>
